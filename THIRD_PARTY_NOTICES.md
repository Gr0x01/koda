# Third-Party Notices

## Appearance pack color schemes

Koda's appearance packs (`src/renderer/src/themes.ts`) reproduce the published color
palettes of several well-known editor themes. The palette values are adapted to Koda's
own token model; the names are those of the original schemes, used nominatively to
identify them. Each is distributed under a permissive (MIT-style) license.

| Pack | Scheme | Author / Project |
|------|--------|------------------|
| Dracula | Dracula | Zeno Rocha & contributors — https://draculatheme.com (MIT) |
| Nord | Nord | Sven Greb (Arctic Ice Studio) — https://www.nordtheme.com (MIT) |
| Solarized Light / Dark | Solarized | Ethan Schoonover — https://ethanschoonover.com/solarized (MIT) |
| Monokai | Monokai (classic) | Wimer Hazenberg — original Monokai color scheme |
| One Dark | One Dark | Atom / GitHub — https://github.com/atom/one-dark-syntax (MIT) |
| GitHub Light / Dark | GitHub (Primer) | GitHub, Inc. — https://github.com/primer/github-vscode-theme (MIT) |

Koda Light and Koda Dark are original to Koda.

1.1** (https://openfontlicense.org). Each font family retains its accompanying
