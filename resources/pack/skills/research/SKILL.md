# Research

Answer the question in the current turn with evidence proportionate to the stakes.

1. Search live when facts may have changed, the topic is uncertain or niche, the user asks for sources, or a recommendation could cost substantial time or money.
2. Prefer primary and authoritative sources. For technical behavior, use official documentation or the primary paper. For news, separate publication date from the date the event happened and compare more than one source when the claim is contested.
3. Use project files and available first-party connectors before a broad web search when they are the actual source of truth.
4. Do not start a background research workflow for an answer the user is waiting on now. Delegate only genuinely independent evidence lanes when doing so materially improves the result.
5. Distinguish sourced facts from your inference. Cite the source beside the claim it supports, and keep quotations short.
6. Stop when the evidence resolves the user's question. Do not turn a bounded lookup into a survey of the field.
